1   Problem Statement

A Shopping Cart application allows users to view products, add products to a cart, update quantities, and remove products from the cart. The application is developed using Vue.js for the frontend, Spring Boot for the backend, and MongoDB for data storage. Objective: Develop this web application considering alternate design options and techniques.

Frontend Layer – Vue.js

The frontend provides the user interface and handles user interactions.

  • Display available products with dynamic category filtering and live search.
  • Add products to the shopping cart with interactive quantity counters.
  • Update or remove products from the cart with real-time reactive feedback.
  • Send requests to the backend service.
  • Display cart details and total amount.

Backend Layer – Spring Boot

The backend processes requests and manages the shopping cart operations using a decoupled service layer.

  • Process requests from the frontend.
  • Add, update, and remove cart items with automated subtotal computation.
  • Calculate the total cart amount.
  • Communicate with the database via Spring Data Mongo Repositories.

Database Layer – MongoDB

MongoDB stores the application data.

  • Main collections: products, cart

2   Alternate Design Options and Techniques

  1. Modular Component Composition: Separates UI concerns into dedicated components (Navbar, ProductCatalog, CartView) with reactive event passing and clean state management.
  2. Live Category Filters & Search: Immediate client-side querying across product categories (Electronics, Audio, Mobile, Wearables, Fashion, Accessories).
  3. Service-Layer Decoupling: Encapsulates cart business logic inside CartService, maintaining clean separation between Spring Boot REST Controllers and Data Repositories.
  4. Indexed MongoDB Documents: Optimized document collections with indexed fields for quick query response times.

3   Full Stack 3-Tier Architecture

The system architecture cleanly decouples the Presentation, Application Business Logic, and Persistence layers.
